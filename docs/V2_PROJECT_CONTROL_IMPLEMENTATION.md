# 片场 V2 项目控制台实现

版本：v0.1

状态：已实现

实现目录：`v2/backend/app/control/`、`v2/frontend/src/pages/DashboardPage.tsx`、`v2/frontend/src/pages/ProjectControlPage.tsx`

## 1. 范围

项目控制台为用户提供跨阶段的只读生产视图。它汇总项目、方案、快照、执行、素材、质量、剪辑、交付、成本和事件事实，不写数据库，不调用 Worker 或供应商，也不提供自动重试、状态修复或路由替换。

## 2. 状态权威

响应同时包含：

- `persisted_status`：Project 表中的权威状态。
- `evaluated_stage`：由现有权威记录计算的页面导航阶段。

阶段投影不写回 Project。完成交付、交付尝试、时间线、质量状态、生产执行、快照和方案按从后到前的优先级判断，因此历史阻断不会遮盖已经成立的后续权威事实。

## 3. 汇总事实

控制台展示：

- 活动方案和活动或最新生产快照。
- 当前快照内 WorkItem 与 Asset 状态计数。
- 快照、工作项、QC 和交付的结构化阻断证据。
- 按币种分离的预计、扣费、调整、退款和待对账事件。
- WorkAttempt 冻结请求清单中的供应商、适配器和工作流，以及实际任务 ID。
- 最近 20 条持久化 ProjectEvent。
- 由当前事实确定的唯一下一步页面、确认等级和费用边界。

错误文案仅用于展示，不参与阻断类型、路由或阶段判断。

## 4. API

```text
GET /api/v1/project-controls
GET /api/v1/projects/{project_id}/control-center
```

列表接口用于首页总控，详情接口用于单项目证据视图。两者都是只读 GET，不创建命令回执或事件。

## 5. 页面

首页 `/` 显示服务状态、项目数量、待审核数量、阻断总数和项目生产列表。每个项目直接展示阶段、工作项进度、活动方案/快照、阻断数量与下一步，并进入 `/projects/{project_id}/control`。

项目详情展示阶段、指标、阻断证据、分币种成本、实际执行路由和最近事件。下一步按钮只导航到现有工作页面，不直接执行业务命令。

## 6. 验收

- 新项目显示需求确认阶段和继续确认需求。
- 未连接适配器失败后显示精确供应商路由、错误码和结构化阻断。
- 已验证最终交付显示完成阶段与下载入口。
- 控制台查询前后数据库状态不发生变化。
- 费用不跨币种合并，未确认事件不进入确认金额。
- 前端桌面和手机布局无页面级横向溢出。
- 查询和页面不引入供应商调用、重试、兜底或隐藏状态转换。
