# 片场 V2 智能体运行审计实现

> 实现日期：2026-07-17
> 范围：创作中心只读运行审计，不包含真实模型接入、重试、取消或恢复。

## 1. 目标

将原有只显示技术状态、模型名和截断 ID 的运行历史，改为普通用户能够理解、工程人员仍可追溯的智能体运行审计视图。

产品统一使用“智能体”表达不同分工：

- `creative`：创意策划
- `director`：分镜导演
- `qc`：质量审核
- `editor`：剪辑助理

内部 `agent_role` 合同保持不变，展示名称不参与路由或状态判断。

持久状态仅做展示翻译，例如 `succeeded` 显示为“已完成”、`validation_failed` 显示为“候选校验失败”、`stale` 显示为“已过期”；未知状态保留原值，不能猜测成已完成。

## 2. 接口投影

创作中心的每条 `AgentRunRead` 增加只读 `input_manifest`：

```text
id
base_requirement_version_id
message_ids[]
decision_ids[]
attachment_binding_ids[]
system_config_version
input_hash
created_at
```

服务按 `AgentRun.input_manifest_id` 精确读取清单，并逐字段构造响应。清单不存在时返回 `null`，不采用同项目最新清单，也不从候选或消息反推。

接口继续返回运行合同、候选 ID、结构化错误和开始/结束时间，但明确不返回 `AgentRun.raw_output`。

## 3. 前端信息层级

默认卡片展示：

- 智能体分工、运行状态和模型名
- 持久化开始/结束时间计算的耗时
- 输入消息、已确认决策和附件绑定数量
- 是否登记了解析后的候选
- 已持久化的错误代码和错误说明

可展开审计详情展示：模型供应商、提示词合同、输出合同、系统配置、基础需求版本、输入哈希和完整运行 ID。长值允许换行，不挤压侧栏。

## 4. 明确边界

- 不返回或展示原始模型输出。
- 不根据错误文字推断状态或建议自动修复。
- 不增加运行、重试、取消、恢复按钮。
- 不创建 AgentRun、候选、消息、决策、事件或费用。
- 不改变模型、Provider、工作流、路由、状态机或确认门禁。
- 不为历史记录补写语义事实。

## 5. 验证

- API 测试证明运行绑定精确基础需求、输入消息、决策、附件绑定、系统配置和 64 位输入哈希。
- API 测试证明 `latest_agent_run` 与历史首项一致，且响应中没有 `raw_output`。
- TypeScript 生产构建验证前端合同和审计界面。
- 完整后端测试、Python 编译、桌面和窄屏浏览器检查作为发布门禁。创作中心在应用侧栏存在时提前切换为两栏，审计长哈希和完整 ID 不得造成横向溢出。
