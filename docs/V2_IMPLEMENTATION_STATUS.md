## 状态定义

- `已完成`：已有持久化合同、API/服务、测试，并在需要时已有可运行页面。
- `部分完成`：已有一部分能力，但尚未满足设计文档中的完整边界。
- `未开始`：没有找到对应实现，或当前明确保留为后续范围。
- `需确认`：实现会改变付费调用、重试、兜底、路由、确认边界或项目状态语义，必须先由用户确认。
